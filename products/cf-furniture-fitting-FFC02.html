FFC02

Upward Door Support Mini Version

  • MaterialIron+Plastic
  • FinishNickel Plated / Black
  • Available forCabinet height KH: 240-500mm; Front width: 500-1500mm; Cabinet depth should be 200mm at least

Features

  • Free stop at any position in opening angle about 30°
  • Door can be closed when used with soft-closing hinges
  • If using with 2 pcs, LF should be double.
  • LF=Cabinet Height KH(mm) x (Cabinet Pull weight x 2 + Front weight) FW (kg)
  • The open angle of the door will be limited by the angle of used hinges
  • KH: Cabinet Height FW: Front Weight
  • If the LF is mixed in 2 areas, we advise to choose the large type.
